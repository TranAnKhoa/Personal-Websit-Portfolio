## 🌐 Introduction

This is a comprehensive web solution designed for an **Academic Professional (Professor/PhD)**. 

The platform serves a dual purpose:
1.  **Personal Branding (Portfolio):** Showcasing academic background, biography, and a digital archive of scientific publications.
2.  **E-Learning Marketplace:** An integrated module allowing the user to publish and distribute online courses (similar to a mini-Udemy), making knowledge accessible to students.

## 🚀 Key Features

### 🔹 For the Professor (Admin)
* **Content Management:** Easy update of biography and achievements.
* **Publication Archive:** Organized listing of research papers with links/downloads.
* **Course Management:** Upload course materials, set descriptions, and manage curriculum.

### 🔹 For Students/Visitors (User)
* **Responsive UI:** Fully optimized for Desktop and Mobile using **Bootstrap Grid System**.
* **Interactive Navigation:** Smooth page transitions and dynamic element handling using **JavaScript**.
* **Course Browsing:** View available courses, read syllabi, and enroll (simulation).

---

## 🛠 Tech Stack

* **Backend:** Python Django Framework (MVT Architecture).
* **Frontend:** HTML5, CSS3, Bootstrap 5.
* **Interactivity:** Vanilla JavaScript (DOM Manipulation, Event Handling).
* **Database:** SQLite (Development env).
